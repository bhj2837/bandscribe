## 탐색 기록: 옥타브 유령 음 (실험으로 등록하지 않음)

DESIGN S7 의 "고립된 옥타브 유령 음"을 dev 곡에서만 살펴봤다(`data/tmp/m8/octave_explore*.py`). 같은 순간(30 ms)에 한 옥타브 아래 짝이
있고 그 짝보다 짧은 위쪽 음은 4,026개 중 97 % 가 가짜였다. 하지만 **3,869개가 moosmusic 한 곡**(기타 스템에 다른 악기가 대량으로
새어 든 곡)에서 나왔다. 나머지 dev 곡에서는 157개 중 가짜가 29개(18 %)뿐이라, 이 규칙을 켜면 정상 곡의 진짜 음(옥타브 겹친 코드)을
지운다. 전체 97 % 는 한 곡이 만든 착시라 실험으로 등록하지 않았다. 교훈: 정밀도는 곡별로 본다(E30 `vocal` 의 dev 0.84 도 같은 착시였다).
