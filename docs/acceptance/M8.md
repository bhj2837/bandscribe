## 탐색 기록: 옥타브 유령 음 (실험으로 등록하지 않음)

DESIGN S7 의 "고립된 옥타브 유령 음"을 dev 곡에서만 살펴봤다(`data/tmp/m8/octave_explore*.py`).

- 같은 순간(30 ms)에 한 옥타브 아래 짝이 있고 그 짝보다 짧은 위쪽 음은 4,026개 중 97 % 가 가짜였다.

- 나머지 dev 곡에서는 157개 중 가짜가 29개(18 %)뿐이다. 이 규칙을 켜면 정상 곡의 진짜 음(옥타브가 겹친 코드)을 지운다.
- 그래서 실험으로 등록하지 않았다. 교훈: 정밀도는 곡별로 본다. E30 `vocal` 의 dev 0.84 도 같은 착시였다.
