## 진단: "틀린 음"의 종류 (Tier A 여섯 곡, 음 29,679개)

| 종류 | 비율 |
|---|---|
| 맞음(그 마디 악보에 같은 음높이가 남아 있음) | 61 % |
| 같은 음높이인데 악보보다 더 많이 나옴(한 음이 쪼개짐, 또는 악보가 줄여 적은 스트럼) | 16 % |
| 같은 음이름, 다른 옥타브 | 13 % |
| 다른 음이름 | 9 % |
| 악보가 쉬는 마디 | 1 % |

곡별로 "더 많이" 11–22 %, 다른 옥타브 8–17 %, 다른 음이름 5–15 % 다(`data/tmp/m10/wrong_kinds.py`). 가장 큰 오류는 엉뚱한 음이 아니라
**쪼개짐과 옥타브**다.
이것을 줄이는 것은 신뢰도 모델이 아니라 전사·음표 정리 단계의 일이다(DESIGN S7 "고립된 옥타브 유령", PROGRESS "S7 note clean-up is the largest
lever"). M8 에서 옥타브 유령 규칙은 정상 곡의 진짜 옥타브 코드를 지워 접었다. 이제 악보 정답 곡이 여섯 개라 그 일을 다시 잴 수 있다.
