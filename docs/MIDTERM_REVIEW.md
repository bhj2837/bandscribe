### 5.2 규칙 (`docs/decisions.md` 맨 앞 "지표와 분할" 블록으로 1-3 에서 적는다)

- 품질 결정의 1차 대상은 악보곡이다. Tier B 는 해가 없는지 보는 확인용이고, 팔 사이 차이로만 인용한다.
- **집계(한 번 정하고 어디서나 같게):** 합친 기타·파트별·베이스 마디 F1 은 풀링(곡별 TP / FP / FN 합)이다. 지금 66.8 / 55.9 / 81.5.
  곡 평균(66.9 / 55.4 / 81.8)은 참고로만 적는다. 떠도는 오프셋 값도 풀링이다(합친 68.9, 베이스 85.6). 구절 비율은 모든 구절을 한데 센
  비율이다(485개 중). "어느 곡도"로 시작하는 규칙만 곡별 값을 쓴다.
- **누적 바닥:** 계획 시작 값(0-3 재실행 뒤)에서 합친 −0.3, 파트별 −0.5, 베이스 −0.2, 구절 비율 −2점. 모든 채택은 실험별 허용 폭과 함께 이
  바닥을 지킨다. 앞의 채택이 여유를 쓰면 뒤 실험의 허용 폭은 남은 여유만큼으로 줄어든다. 3 / 3 분할이면 dev 와 test 각각의 시작 값에 같은 폭을
  적용한다. 악보 6곡 기준 바닥은 66.5 / 55.4 / 81.3, 구절 24.6 % 다.
- **분할(마감 있음):** 1단계 끝(11/15)에 1-3 에서 커밋한다.
  - 그때까지 봉인 음원이 와서 판본 관문을 통과한 곡이 5곡 이상이면 dev = 지금 6곡, test = 봉인 곡.
  - 아니면 지금 6곡을 3 / 3 으로 잠근다. 후보는 test = SC, SNN, GKA / dev = ANB, HBT, HNN 이다. 꽉 찬 코드를 스트럼하는 곡(HBT, SNN,
    HNN, GKA)이 양쪽에 2곡씩이고, 이미 조정된 팔과 겹치는 곳이 가장 적은 조합이다. test 에는 "이미 본 곡" 단서를 붙인다.
  - 3 / 3 이면 그 뒤의 모든 개발(2-3 시뮬레이션, 2-6 사전 점검, E43 특징 선택, E45 임계값 조정, E46 팔 선택, 3-5 탐색)은 dev 3곡만 쓴다.
  - 이미 특정 곡에서 조정된 팔: E45 의 임계값(0.3–0.7, 0.42)은 GKA·ANB·HBT·HNN 의 겹친 다운비트 4건에서 왔다. E46 의 최저음 팔은
    HBT(81.3 → 85.7)에서 찾았다. E42 는 18파트 전체를 보고 만들었다. 그 곡이 test 에 있으면 그 실험의 test 판정에서 빼거나 "표본 안, 잠정"으로
    적고, 봉인 곡이 오면 다시 판정한다. 위 후보 분할이면 E45 의 GKA 와 E42 의 SNN 이 해당한다.
  - 마감 뒤에 봉인 음원이 오면 분할은 바꾸지 않는다. 봉인 곡은 추가 시험셋으로 ③·④ 보기에서 함께 보고, "표본 안, 잠정" 판정을 다시 한다.
- **봉인:** 분할을 커밋한 뒤에만 점수를 낸다. test 는 등록된 항목의 `bandscribe eval exp <id>` 로만 읽고, 읽을 때마다
  `data/eval/test_access.log` 에 남긴다. 보는 횟수 예산은 4번이다: ① 분할 커밋 뒤 기준선(11/15), ② 2단계 묶음(E42 확인, E43), ③ 3단계
  묶음(E45, E44, E46, E47, 준비됐으면 E21·E48), ④ 마지막 전체 확인. E21·E48 이 ③에 못 맞추면 예비 ⑤를 쓴다(미리 등록).
- **불확실성:** 곡 부트스트랩 CI. 6곡이면 합친 F1 ±4.5점이라 최소 검출 차이를 2–3점으로 잡는다. 이득을 주장하는 채택 문턱은 이보다 낮게 두지
  않는다(E21·E48 은 +3). 3곡 test 의 CI 는 판정에 쓰지 않는다(곡 다시 뽑기가 10가지뿐이다). 스트럼·구절 수를 n 으로 CI 를 내지 않는다.
- **등록 양식:** 기존 항목에 "이탈(deviation)" 칸과 "구절 비율 기대 효과(방향, 크기)" 칸을 더한다. 결과를 본 뒤 정답이나 규칙을 바꾸면 새
  번호로, 새 곡에서 판정한다.
- **실버 규칙(사전 등록):** 세션 1 은 dev 악보곡 중 사용자가 연습하지 않은 곡으로, 악보를 닫고 한다. 거기서 사용자 교정과 악보의 음 일치가
  0.85 이상일 때만 J-pop 실버 음 F1 을 헤드라인으로 쓴다. 아니면 평점과 분만 보고한다. 악보가 틀린 곳(사용자 귀가 맞는 곳)은 따로 표시해 악보
  자체의 오류율도 함께 본다.
- **임계값 검증(사전 등록):** "구절 F1 0.7 이상 = 연습 가능" 을 사용자 평점(1 그대로 연주 가능, 2 두 군데 이하 수정, 3 많이 손봄)과 비교한다.
  악보가 있는 평점 구절이 8개(32마디) 이상 모이면 판정한다: 평점 1–2 와의 일치가 0.7 이상이면 유지, 아니면 다음 계획에서 다시 정한다. 이번
  계획의 세션 1 은 평점 8마디(2구절)라 기록만 한다.
- 모든 주장은 "Kessoku Band / 한 채보자" 범위로 적는다. J-pop 은 항상 별도 표다.
